# DensaMed Smart Sales Pro — Odoo 17 Community

Install **densamed_sale** first, then install **densamed_sale_pro** from Apps. Upgrade the app after updating code. Existing FEFO, prescription, stock picking, return, split-payment and receipt workflows remain in the base module.

Features: date-filtered dashboard KPI cards; Odoo graph/pivot sales analytics; customer history, VIP/regular/new segmentation and loyalty points; simple historical-average demand forecast and popular products chart; warehouse stock threshold rules and low-stock view; unique per-branch promo codes, automatic discounts, redemption limits; PDF performance report; existing sales/payment/return workflows.

**Important:** Forecast is statistical, NOT machine-learning AI. Loyalty points are accrued and displayed, not redeemable. Excel export uses Odoo built-in list-view export (select rows > Action > Export) rather than a custom XLSX generator. Alerts are visible in the stock-alert menu; automatic email/push notifications are not implemented. Test on a staging database before production. This add-on has not been validated against a running Odoo server.
